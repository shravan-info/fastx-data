About Fastx & Site Removal (DMCA)

Fastx is an educational, zero-cost, serverless search engine. We do not host copyrighted web content—we only crawl publicly available titles and short snippets, directing users to original creators.

Attributions & Data Sources:

  • Weather forecast data provided by Open-Meteo.com (Non-Commercial Educational License) [1.3.1, 1.3.4].
  • Encyclopedia summaries and thumbnail images via Wikimedia API (CC BY-SA 4.0 / Public Domain) [1.2.1, 1.2.2].
  • Academic literature via OpenAlex API.

Website Removal / Contact:

If you are a webmaster and want your URL removed from our index, please email our GitHub repository or contact: admin@fastx-search.pages.dev. We honor all robots.txt and valid removal requests within 24 hours.
